# Filled Magazines (Project Zomboid, Build 42)

Magazines found as world loot spawn already loaded with ammunition.

- Sandbox options (page "Filled Mags"): chance a magazine is loaded, minimum and maximum fill.
- Admin tool: right-click a magazine in your inventory -> "[Admin] Fill magazine" (debug mode or server admins with item-edit rights).

## Install for development
Copy `Contents/mods/FilledMags` into `~/Zomboid/mods/` and enable "Filled Mags" in the Mods menu.
